# lnwjud v5.8.0 Desktop usability follow-up

Scope: existing `dev` branch and existing v5.8.0 Goal; no new worktree, no merge/tag/release. Change only production UX, native file browsing, portable startup feedback, and resources justified by evidence.

## Root causes observed in installed screenshots
- Workflow cards and inputs shipped without CSS rules for their new classes. Raw inline labels/inputs overflow on normal desktop widths.
- File paths were plain text fields, with no native Browse action.
- Git and other filter dropdowns depended on host-native select popups, which did not match dark theme and could not be searched.
- Portable NSIS extraction precedes Electron startup; an Electron-only splash cannot inform the user during extraction.
- ECC is installed as a pinned optional skill/rule/catalog provider; actual activation and resource usage require checking call paths, not assuming a background daemon.

## Implementation sequence / acceptance
1. Central searchable combo box: controlled options/value/search, keyboard navigation, selection, empty state, consistent sizing, theme and focus.
2. Migrate user-facing filters (Git status/project, Tool catalog filters, logs/worklog workspace and session, Call History transport, Workflow enums and primary workspace). Keep plain text search inputs as text inputs.
3. Workflow cards/fields: responsive grid, spacing tokens, field labels over controls, visible file Browse, preserve manual paths; Electron main owns native dialog with strict trusted-sender/no-payload checks. File validation remains in the workspace-bound workflow service.
4. Portable launch: use NSIS portable splash image during extraction before Electron exists; do not report a fabricated percent.
5. ECC: verify catalog and activation call sites; prefer current selective, cached, demand-loaded provider, remove eager startup work only if measured.
6. Validate functional tests, TypeScript, lint, canonical release gate and Windows packaging; push `dev`, monitor exact-SHA GitHub CI until green. Build new local Setup and Portable for operator smoke; do not publish.

## Boundaries and deferred checks
- File selection does not relax workspace containment, realpath, or path symlink checks.
- Avoid broad restyling of settings forms without measured UI reproduction.
- Manual installed Portable/Setup UX remains an operator smoke test; no claim of zero bugs.
- Windows signing certificate is not configured; local unsigned binaries may show SmartScreen.
